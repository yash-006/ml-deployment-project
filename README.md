# ML Deployment Project

A simple machine learning deployment project using Python, Scikit-learn, FastAPI, and Uvicorn.

## Project Flow

Dataset
→ Model Training
→ Saved Model
→ FastAPI
→ /predict
→ Prediction

## Technologies

- Python
- Pandas
- Scikit-learn
- FastAPI
- Uvicorn
- Joblib
